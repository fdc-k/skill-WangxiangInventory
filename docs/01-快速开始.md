# 01 · 快速开始（5 分钟跑通一遍）

> 前提：已经双击过安装脚本（`bin` 里的 `setup.bat` 或 `setup.command`），
> 并且 `config/config.yaml` 里已经填好网址和密钥。
> 没做过的话，先看 [02-安装与环境准备](02-安装与环境准备.md)。

下面用 `XXX` 表示跟你的系统有关的命令。**照着你的系统选一行即可**：

| | Windows | Mac |
|---|---|---|
| 运行方式 | 双击 `bin\xxx.bat` | 双击 `bin\xxx.command` |
| 命令行方式 | `.venv\Scripts\python -m wangxiang xxx` | `.venv/bin/python -m wangxiang xxx` |

---

## 第 0 步：先检查

双击 **`bin\4-离线自检.bat`**（Mac 是 `4-离线自检.command`）。

看到最后一行是 `✅ 自检全部通过。` 就说明工具本身没问题。
它不联网、不改数据，随时可以跑。

---

## 第 1 步：读取库存文件

双击 **`1-提取库存`**。

窗口里会出现类似这样的内容：

```
  [SP5] SP5 蜘蛛库存表：84 行 / 18 个商品 -> SP5_统一库存.xlsx
  [ALO] ALO 库存表：73 行 / 15 个商品 -> ALO_统一库存.xlsx
  [PALLET] Essentials 货盘 PDF：850 行 / 130 个商品 -> PALLET_统一库存.xlsx

完成：共 1007 行库存。
```

去 **`output/unified`** 文件夹看结果。每个来源变成一个格式相同的 Excel。

---

## 第 2 步：看和网店的差异

双击 **`2-差异比对`**。

第一次会从网店拉数据，约 1~2 分钟；以后会快很多。

跑完窗口里会出现：

```
===== 比对结果 =====
  有差异: 72
  一致: 482
  需要人工处理: 453

  彩色报表（网页，双击即可看）：output/diff/库存差异_xxx.html
```

**报表文件夹会自动打开。** 双击里面那个 **`.html`** 文件（用浏览器打开），
红色 = 和网店不一样，绿色 = 一样，黄色 = 网店里没这个商品。

> 这一步**不会改动网店**，随便跑。

---

## 第 3 步：确认后更新

双击 **`3-同步更新`**。

它会**先演练一遍**（把准备改的全部列出来，但什么都不提交），
然后问你：

```
确认要真正更新网店吗？输入 YES 再按回车（其它任何输入=取消）：
```

- 输入 **`YES`** → 真的更新
- 输入别的 → 取消，网店一点没动

更新完成后，去 **`output/sync`** 看结果：
每一条都写着「更新前 → 更新后」和成功/失败。

---

## 做完之后

- **下次再更新**：把新的库存文件覆盖进去，重复第 1、2、3 步。
- **改错了**：`output/sync` 里有"回滚快照"，可以让工具帮你撤回。
- **报表里有很多黄色？** 说明网店还没有这些商品，看
  [06-商品映射表说明](06-商品映射表说明.md)。

---

## 一句话记住三条规矩

1. **不确认，不更新。** 只有你输入 `YES`，工具才会动网店。
2. **每次更新都留后悔药。** 随时能撤回。
3. **看不懂就双击"离线自检"。** 它不说谎，也不会改任何东西。
