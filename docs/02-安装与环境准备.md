# 02 · 安装（一次就好）

## 你需要什么

| 需要 | 说明 |
|---|---|
| 一台电脑 | Windows 10/11，或者 Mac |
| 网络 | 只有"安装"和"更新网店"时需要 |
| WooCommerce 密钥 | 只有 3 行，见 [04](04-WooCommerce密钥获取.md) |

**不需要**装 Excel、**不需要**数据库、**不需要**买任何东西。

---

## 最简单的安装方式：双击

打开项目文件夹 → 进入 **`bin`** 文件夹 → 双击：

| 你的电脑 | 双击这个文件 |
|---|---|
| Windows | **`setup.bat`** |
| Mac | **`setup.command`** |

会弹出一个黑色窗口，自动完成下面这些事：

1. 找一个能用的 Python（**优先用 WorkBuddy 自带的**，找不到才用你电脑上的）
2. 在项目里建一个独立环境 `.venv`
3. 把需要的库装进去
4. 生成一个方便的 `wangxiang` 短命令
5. 如果没有配置文件，就从模板复制一份

**第一次需要联网，等 1~3 分钟。** 最后你会看到：

```
==========================================================
 装完了！下面跑一次离线自检（不联网）
==========================================================
✅ 自检全部通过。

==========================================================
 接下来做什么
==========================================================
  1) 打开 config/config.yaml，填 3 个地方：
```

看到"自检全部通过"就装好了。

> **这个脚本可以反复双击**，不会弄坏东西。装出问题了就再双击一次。

---

## 装的时候到底装了什么？

| 装的东西 | 干什么用的 | 装在哪 |
|---|---|---|
| Python 运行环境 | 跑这个工具 | 项目里的 `.venv` 文件夹 |
| `openpyxl` | 读写 Excel | 同上 |
| `pdfplumber` + `numpy` | 读 PDF 货盘、判断打勾 | 同上 |
| `requests` | 连你的网店 | 同上 |
| `PyYAML` | 读配置文件 | 同上 |

**全部装在项目自己的 `.venv` 文件夹里**，不会污染你电脑上的其它程序。
不喜欢了，直接删掉 `.venv` 文件夹就干净了。

---

## 如果提示"没有找到 Python"

### 你用 WorkBuddy？

**先打开一次 WorkBuddy 软件**（它会自动准备自带的 Python），
然后回来重新双击 `setup.bat` / `setup.command`。

### 没用 WorkBuddy？

| 系统 | 怎么做 |
|---|---|
| **Windows** | 去 <https://www.python.org/downloads/> 下载安装。**安装第一屏必须勾上 `Add python.exe to PATH`**，否则后面还会报错 |
| **Mac** | 打开"终端"，输入 `xcode-select --install` 回车，按提示装完；或者同样去 python.org 下载 |

装完重新双击 `setup` 就好。

---

## 安装后检查三件事

| 检查 | 怎么做 | 应该看到 |
|---|---|---|
| 依赖装齐了 | 双击 `bin\4-离线自检` | `✅ 自检全部通过。` |
| 配置文件在 | 看有没有 `config/config.yaml` | 有 |
| 密钥填了 | 双击 `bin\setup`（会跑 check） | `✅ 连接成功` |

---

## 路径建议（Windows 特别注意）

把项目放在**简单、短的路径**下，例如：

```
C:\wangxiang            ✅ 好
C:\Users\张三\桌面\新文件夹\库存\skill-WangxiangInventory    ❌ 容易出问题
```

Mac 同理，放 `~/wangxiang` 这种就很好。

---

## 命令行方式（可选，给习惯用终端的人）

```bash
# Mac / Linux
cd 你的项目目录
python3 tools/bootstrap.py

# Windows（命令提示符或 PowerShell）
cd /d C:\wangxiang
py -3 tools\bootstrap.py
```

效果和双击完全一样。

---

## 想卸载？

1. 删掉项目里的 `.venv` 文件夹 —— 所有依赖就没了
2. 删掉整个项目文件夹 —— 彻底干净

不会在系统里留任何东西。
